# 🎯 Guess the Number Game (Python)

A simple and interactive number guessing game developed using Python. The computer generates a random number between 1 and 100, and the player tries to guess it within 7 attempts.

## ✨ Features

- Generates a random number between 1 and 100.
- Allows the player up to 7 attempts.
- Provides hints to guess a higher or lower number.
- Displays a success message when the correct number is guessed.
- Shows the correct number if the player runs out of attempts.

## 🛠️ Technologies Used

- **Language:** Python
- **Module:** `random`

## 🚀 How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python guess_the_number.py
   ```

## 🎮 How to Play

1. Run the program.
2. Enter a number between 1 and 100.
3. Follow the hints:
   - **Higher number please** — try a higher number.
   - **Lower number please** — try a lower number.
4. Guess the correct number within 7 attempts to win!

## 📚 Learning Outcomes

- Using Python's `random` module.
- Working with loops and conditional statements.
- Taking user input and converting it to an integer.
- Using variables to track the number of attempts.
